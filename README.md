# A Picture of You

Website for A Picture of You Photography (Graham Gibson), Station Road, Ossett. Built with Astro 7, TypeScript, Tailwind CSS 4 and Motion, deployed on Vercel.

## Develop

```sh
npm install
npm run dev      # http://localhost:4321
npm run check    # type-check
npm run build
```

Copy `.env.example` to `.env` and add `RESEND_API_KEY` to send contact form emails. Without it, enquiries are logged to the server console.

## Where things live

| What | Where |
| --- | --- |
| Business details, nav, external links | `src/data/site.ts` |
| Pricing packages | `src/data/packages.json` |
| Testimonials | `src/data/testimonials.json` |
| Photos and alt text | `src/data/photos.ts`, `src/assets/photos/` |
| Colours, type, motion | `src/styles/global.css`, `astro.config.mjs` (fonts) |
| Contact form handler | `src/actions/index.ts` |
| Security headers | `vercel.json` (CSP is generated by Astro) |

## Placeholder content

`src/assets/photos/temp/` holds CC0 stand-in photos from Wikimedia Commons (Unsplash CC0 uploads). Swap them for Graham's own work by replacing the imports in `src/data/photos.ts`. In dev, temp photos in galleries show a small "temp" badge. Search for `TODO(graham)` for details still to confirm (postcode, opening hours, portrait of Graham).

Client galleries and the print shop stay on Zenfolio and are linked from the nav.
